# 🎁 Amigo Secreto

Aplicação web para criação e gerenciamento de sorteios de **Amigo Secreto**, com foco em simplicidade, usabilidade e compartilhamento fácil via WhatsApp.

## ✨ Funcionalidades

- Criar grupos de amigo secreto
- Definir se o administrador participa ou não do sorteio
- Geração automática de links exclusivos:
  - Link de administrador
  - Link de participante
- Cadastro de participantes com:
  - Nome
  - Telefone (WhatsApp)
  - Até 3 sugestões de presente (opcional)
- Painel administrativo para:
  - Visualizar participantes
  - Realizar o sorteio
  - Enviar links/resultados via WhatsApp
- Página individual para cada participante visualizar seu amigo secreto
- Interface simples e responsiva
- Efeitos visuais no resultado do sorteio 🎉

## 🛠️ Tecnologias Utilizadas

- **Next.js**
- **React**
- **TypeScript**
- **JavaScript**
- **Tailwind CSS**
- **Vercel** (deploy)

## 🚀 Como rodar o projeto localmente

```bash
# Clone o repositório
git clone https://github.com/alexsantos-djesus/amigo-secreto.git

# Entre na pasta do projeto
cd amigo-secreto

# Instale as dependências
npm install

# Rode o projeto em modo desenvolvimento
npm run dev
```

Acesse em:  
👉 http://localhost:3000
